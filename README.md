# Q-SECURE
Q-SECURE mô phỏng giao thức Phân phối Khóa Lượng tử (QKD BB84) kết hợp cơ quang học, mạng TCP/IP và mã hóa ảnh XOR. Dùng ESP32, Servo và cảm biến LDR để số hóa góc phân cực thành bit logic, phần mềm PyQt6 tự động chạy thuật toán Sifting tạo khóa, tính tỷ lệ QBER phát hiện nghe lén và mã hóa/giải mã ma trận ảnh OpenCV thời gian thực.
